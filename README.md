# Azure Architecture Labs

Hands-on labs built to practise Azure and Microsoft identity architecture, one realistic scenario at a time. Each lab is built in a home lab (VMware, pfSense, Windows Server, Linux) connected to a real Microsoft cloud tenant, and documented with a step-by-step guide, design decision records and scripts.

## How each lab is documented

- **README:** the problem, the architecture diagram, results and lessons learned
- **Build guide:** every step with the reason behind it
- **ADRs:** one short record per design decision (context, options, decision, why, trade-offs)
- **Scripts:** the commands, ready to re-run

Sensitive values (tenant name, IDs, public IP addresses) are replaced with placeholders or blurred.
